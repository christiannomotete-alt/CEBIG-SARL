# CEBIG SARL - Structure du Projet

## 📁 Organisation des Fichiers

```
CEBIG SARL/
├── index.html          # Fichier HTML principal
├── css/
│   └── style.css       # Feuille de style CSS
├── js/
│   └── script.js       # Fichier JavaScript
└── images/ (à créer)   # Dossier pour les images
```

## 📄 Description des Fichiers

### **index.html** (Fichier Principal)
- Contient la structure HTML du site complet
- Inclut toutes les sections : Header, Hero, À Propos, Expertises, Réalisations, Contact, Footer
- Fait appel aux fichiers CSS et JavaScript

### **css/style.css** (Feuille de Style)
- Tous les styles visuels du site
- Variables CSS pour les couleurs et transitions
- Responsive design avec media queries
- Animations et effets de hover

### **js/script.js** (Interactivité)
- Menu mobile responsive (burger menu)
- Gestion du formulaire de contact
- Smooth scroll pour les ancres
